# Mockups

Interactive HTML mockups of MX400 controller. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [MX400_Library](mockups/MX400_Library.dc.html)
